What is JSON?

JSON is the structured data format our API sends and receives.

{
  "id": 5,
  "name": "Student",
  "email": "student@example.com",
  "date_of_birth": "2001-02-03"
}

It looks similar to a Python dictionary, but JSON is a data exchange format.

What is a REST API?

It uses HTTP methods and predictable URLs to work with data.

GET     /account/api/registrations/     -> Read all
POST    /account/api/registrations/     -> Create
GET     /account/api/registrations/5/   -> Read one
PATCH   /account/api/registrations/5/   -> Update part
DELETE  /account/api/registrations/5/   -> Delete

Point 8

Serializer: converter and validator

class RegistrationSerializer(serializers.ModelSerializer):
    class Meta:
        model = Registration
        fields = ['id', 'name', 'email',
                  'password', 'date_of_birth']

Outgoing: model object → JSON-ready data

Incoming: JSON → validated model-ready data

10
Point 9

ViewSet: the API controller

class RegistrationViewSet(viewsets.ModelViewSet):
    queryset = Registration.objects.all()
    serializer_class = RegistrationSerializer

queryset: which database data to use.

serializer_class: how to convert and validate that data.

It controls list, create, retrieve, update, and delete.

Point 10

Router: automatic URL maker

router = DefaultRouter()
router.register('registrations', v.RegistrationViewSet)

path('api/', include(router.urls))

This one registration creates list, create, detail, update, and delete URLs.

Router connects URLs to the correct ViewSet actions.

5
Main Purpose

Why use an API?

The main reason is separation and reuse, not security or speed.

Website

Uses the JSON.

Mobile app

Uses the same JSON.

Other software

Uses the same JSON.

Each client decides how to display the data.

6
HTTP

How do clients ask an API?

They send an HTTP request. The method says what they want to do.

MethodMeaningCRUD
GETRead dataRead
POSTCreate dataCreate
PUT / PATCHUpdate dataUpdate
DELETEDelete dataDelete
7
REST

What is a REST API?

A REST API uses URLs and HTTP methods in a clear, predictable way.

GET    /registrations/     -> read all
POST   /registrations/     -> create
GET    /registrations/5/   -> read one
PATCH  /registrations/5/   -> update part
DELETE /registrations/5/   -> delete
8
Tools

Django, DRF, and FastAPI

ToolSimple meaning
DjangoFull Python web framework; can return HTML.
DRFDjango package that makes REST APIs easier.
FastAPISeparate Python framework focused on APIs.

DRF and FastAPI both build APIs. We use DRF because this project is already Django.

9
FastAPI Basics

What is FastAPI?

FastAPI is a Python framework mainly made for building APIs.

HTTP request
→
FastAPI
→
Python logic
→
JSON response

It validates incoming data and can generate API documentation automatically.

10
FastAPI Example

A very small FastAPI endpoint

from fastapi import FastAPI

app = FastAPI()

@app.get("/hello")
def hello():
    return {"message": "Hello"}

GET /hello returns JSON: {"message": "Hello"}

11
FastAPI Features

What does FastAPI give us?

Routes

Connect methods and URLs to Python functions.

Validation

Checks incoming request data.

API docs

Provides an interactive /docs page.

FastAPI is the tool. REST is the API design style.

12
Request

Method + URL is one API instruction

GET /account/api/registrations/

Meaning: “Give me all registrations.”

curl -X GET http://127.0.0.1:8001/account/api/registrations/

curl sends the request. -X GET chooses the method.

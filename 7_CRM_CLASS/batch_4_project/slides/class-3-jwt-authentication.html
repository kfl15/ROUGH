3
Meaning

What is JWT?

JWT = JSON Web Token

A JWT is a signed digital identity card returned after successful login.

Contains

User identity and expiry information.

Signed

Changes to it can be detected.

Not encrypted

Never store passwords inside it.

5
Two Tokens

Access token and refresh token

Access token

Short life. Sent to protected APIs.

Refresh token

Longer life. Creates a new access token.

Access expires
→
Send refresh
→
New access token
6
Bearer

How is the access token sent?

Authorization: Bearer <access_token>

Bearer means: “I am carrying this access token.”

Bearer is not an API. It is the authentication header format.

Step 3

Tell DRF to recognize JWT

crm/crm/settings.py

REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': (
        'rest_framework_simplejwt.authentication.JWTAuthentication',
    ),
}

Now DRF can verify Bearer <access_token>.

10
Step 4

LoginSerializer: receive login data

crm/registration/serializers.py

class LoginSerializer(serializers.Serializer):
    email = serializers.EmailField()
    password = serializers.CharField(write_only=True)

write_only=True means the password is accepted as input but not returned.

11
Step 4 Continued

Check credentials and create tokens

user = User.objects.filter(email=data['email']).first()

user = authenticate(
    username=user.username,
    password=data['password']
)

refresh = RefreshToken.for_user(user)

return {
    'refresh': str(refresh),
    'access': str(refresh.access_token),
}
12
Step 5

LoginAPIView: control the request

crm/registration/views.py

class LoginAPIView(APIView):
    permission_classes = [AllowAny]

    def post(self, request):
        serializer = LoginSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        return Response(serializer.validated_data)

AllowAny: users can attempt login before having a token.

Step 8

Create a protected Profile API

class ProfileAPIView(APIView):
    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            'id': request.user.id,
            'username': request.user.username,
            'email': request.user.email,
        })

request.user is identified from the valid access token.

Step 9

Protect Registration CRUD

class RegistrationViewSet(viewsets.ModelViewSet):
    queryset = Registration.objects.all()
    serializer_class = RegistrationSerializer
    permission_classes = [IsAuthenticated]

Now every Registration CRUD request needs a valid access token.
